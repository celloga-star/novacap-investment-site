# NovaCap — Protótipo React (Vite + TS + Tailwind)

Instalação:
1. npm install
2. npm run dev
3. Abra http://localhost:5173

Observações:
- Este é um protótipo visual; não processa dinheiro.
- Próximos passos: adicionar autenticação (Auth0/Clerk), backend (NestJS/Express + Postgres), integração com market-data (Finnhub/AlphaVantage), e módulos KYC/Compliance para operação real.
